# ✅ NOFX - Gratis API Points untuk Claude/GPT/Gemini via Check-in Harian + Task

**Provider:** NOFX

nofx.one adalah gateway API AI dengan sistem 'API points' berdenominasi dolar yang bisa didapat gratis tanpa kartu kredit. Landing page-nya memasang CTA "Sign up for $20 points" dan saat ini ada 4 task terbuka: gabung Discord (+$5), check-in harian (+$5 per hari kalender Beijing), undang teman (+$5 per teman yang berhasil registrasi), dan share ke X dengan kode undanganmu lalu upload screenshot untuk direview (+$20). Satu API key dipakai untuk beberapa model utama (Claude/GPT/Gemini) lewat endpoint api.nofx.one, dan situs menyediakan konfigurasi siap pakai untuk Codex CLI (termasuk mode WebSocket), Claude Code, Gemini CLI, Grok CLI, dan OpenCode. Login tanpa password (magic link email) atau lewat GitHub. Catatan penting: points sisa dihapus setelah 30 hari berturut-turut tanpa pemakaian API nyata, dan check-in berhenti otomatis kalau saldo + pending melebihi $50.

> **Status:** Aktif

⏰ **Info Waktu:** Tidak ada tanggal akhir resmi untuk task dan check-in; Terms of Service berlaku sejak 23 Agustus 2026 dan menyatakan model, multiplier, points, serta daftar task bisa berubah kapan saja

## Keuntungan

- Check-in harian +$5 API points (sekali per hari kalender Beijing)
- Gabung server Discord NOFX lalu jalankan /verify → +$5 API points
- Undang teman lewat link referral → +$5 API points per teman yang berhasil registrasi
- Share ke X dengan kode undanganmu + upload screenshot untuk review → +$20 API points
- Satu API key untuk model utama (Claude/GPT/Gemini) via api.nofx.one, tanpa perlu kartu kredit
- Konfigurasi siap pakai untuk Codex CLI, Codex CLI WebSocket, Claude Code, Gemini CLI, Grok CLI, dan OpenCode

## Persyaratan

- Registrasi pakai email penyedia besar; alias +tag ditolak dan titik di Gmail diabaikan (satu mailbox = satu akun)
- Login tanpa password (magic link email, kedaluwarsa 10 menit) atau lewat GitHub
- Points sisa masuk penghapusan setelah 30 hari berturut-turut tanpa request API valid; jendela 30 hari dihitung sejak reward pertama masuk dan direset tiap request API valid
- Check-in harian dinonaktifkan otomatis kalau points sisa + pending melebihi $50 — habiskan dulu sebagian
- Bukan layanan SLA/high-availability; points bukan uang, tidak bisa ditarik, direfund, dijual, atau dipindahkan
