# ✅ TokenForge Free Beta - 100 Request/Hari + Akses GLM-5.2 & Grok 4.5

**Provider:** TokenForge

TokenForge adalah gateway AI OpenAI-compatible yang saat ini membuka controlled free beta: akun baru menerima kredit promosi tanpa checkout atau pembayaran apa pun. Tier gratis Explorer memberi 100 request per hari dan 100.000 token per hari untuk model GLM-5.2 dan Grok 4.5 lewat satu endpoint /v1/chat/completions. Tersedia juga katalog 37 model teks terverifikasi mulai dari Claude Opus 5, Claude Fable 5, GPT-5.5, o3, Gemini 2.5 Flash, DeepSeek V4 Pro, Kimi K3, hingga Mistral Large 3, dengan tarif kredit per rute yang dipublikasikan terbuka (tarif upstream resmi plus platform charge transparan 1.5 kali).

> **Status:** Aktif

⏰ **Info Waktu:** Controlled free beta tanpa tanggal akhir yang diumumkan; kuota dan ketersediaan model bisa berubah sewaktu-waktu

## Keuntungan

- Gratis total selama masa controlled free beta - tidak ada checkout maupun pembayaran yang diaktifkan
- Tier Explorer $0 dengan kuota 100 request per hari dan 100.000 token per hari
- Akses model GLM-5.2 dan Grok 4.5 lewat satu endpoint kompatibel OpenAI
- Katalog 37 model teks: Claude Opus 5, Claude Fable 5, GPT-5.5, o3, Gemini 2.5 Flash, DeepSeek V4 Pro, Kimi K3, Mistral Large 3, MiniMax M2.7, dan lainnya
- Tarif kredit per rute dipublikasikan transparan: tarif token upstream resmi plus platform charge 1.5 kali

## Persyaratan

- Sign-in wajib memakai akun GitHub karena itu satu-satunya metode login
- Akun GitHub minimal berumur 14 hari dan memakai alamat email permanen yang sudah terverifikasi
- Kuota harian dibatasi 100 request dan 100.000 token per hari selama beta
