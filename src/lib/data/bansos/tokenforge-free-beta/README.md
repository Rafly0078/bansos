# ✅ TokenForge - $40 Referral Credit + $50 Introductory Credit via Akun GitHub

**Provider:** TokenForge

TokenForge (tokenforge.ai.studio) adalah gateway API AI kompatibel OpenAI yang fokus pada katalog model terkurasi. Login satu-satunya adalah GitHub OAuth, dan akun baru otomatis menerima $50 introductory build credit setelah verifikasi awal — tanpa checkout maupun kartu kredit. Mendaftar lewat link referral memberi tambahan $40 referral credit setelah verifikasi. Katalog modelnya mencakup GPT-6 Astra, Claude Opus 5, dan Sonnet 4.6 lewat satu endpoint, dengan opsi langganan bulanan opsional ($10/$25/$50) untuk inference credits tambahan. Program free beta lama di domain manus.space sudah tidak aktif; domain resminya sekarang tokenforge.ai.studio.

> **Status:** Aktif

⏰ **Info Waktu:** Program kredit referral dan introductory berjalan tanpa tanggal akhir yang diumumkan; nominal kredit dan ketersediaan model dapat berubah sewaktu-waktu

## Keuntungan

- $50 introductory build credit otomatis untuk semua akun baru setelah verifikasi awal
- Daftar lewat link referral → tambahan $40 referral credit setelah verifikasi
- Akses model GPT-6 Astra, Claude Opus 5, dan Sonnet 4.6 lewat satu endpoint kompatibel OpenAI
- Tanpa checkout maupun kartu kredit untuk kredit gratis
- Opsi langganan bulanan ($10/$25/$50) dengan 2.400/7.500/16.000 inference credits untuk pemakaian lebih besar
- Dashboard referral untuk melacak kredit dari undangan

## Persyaratan

- Sign-in wajib memakai akun GitHub karena itu satu-satunya metode login
- Akun GitHub minimal berumur 14 hari dan memakai alamat email permanen yang sudah terverifikasi
- Kredit diberikan setelah verifikasi akun, bukan saat pendaftaran
